## Публикация проекта

Проект автоматически деплоится на GitHub Pages при пуше в основную ветку приватного репозитория.

### Ссылка на опубликованный проект:
👉 [https://deputattyulkino.github.io/mesto-production/](https://deputattyulkino.github.io/mesto-production/)

### Процесс деплоя:
1. Закоммитьте изменения:
```bash
git add .
git commit -m "feat: готов к деплою"
```

2. Запушите в основную ветку для запуска CI/CD:
```bash
git push origin main
```
